# Variable coding (from the UCI page)

- Gallstone Status: 0 = Yes, 1 = No (note: reversed from the usual convention)
- Gender: 0 = Male, 1 = Female
- Comorbidity: 0 = none, 1 = one condition, 2 = two, 3 = three or more
- Coronary Artery Disease: 0 = No, 1 = Yes
- Hypothyroidism: 0 = No, 1 = Yes
- Hyperlipidemia: 0 = No, 1 = Yes
- Diabetes Mellitus: 0 = No, 1 = Yes
- Hepatic Fat Accumulation (HFA): 0 = none, 1 = Grade 1 (mild), 2 = Grade 2 (moderate), 3 = Grade 3 (severe), 4 = Grade 4 (very severe)
